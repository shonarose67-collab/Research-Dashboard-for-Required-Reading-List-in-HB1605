# HB 1605: Research-Linked Evidence Dashboard

## Overview
This is a comprehensive, evidence-based research dashboard analyzing Texas House Bill 1605 and the proposed required reading list for Texas schools. The site presents critical findings on text complexity, feasibility, diversity, and quality review from educational research perspectives.

## Purpose
The dashboard serves educators, policymakers, and the general public by providing:
- Research-backed analysis of HB 1605
- Evidence on text complexity and grade-level appropriateness
- Feasibility assessments
- Diversity audit findings
- Remediation recommendations

✅ **Responsive Design** - Works on desktop, tablet, and mobile devices

## Getting Started

### Local Setup
1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process or dependencies required!

### GitHub Pages Deployment
1. Push files to GitHub repository
2. Go to Settings → Pages
3. Set Source to "Deploy from a branch"
4. Select branch: `main`
5. Your site will be live at: `https://yourusername.github.io/repo-name`
